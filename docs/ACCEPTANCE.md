Стандартный playwright install chromium пытался получить архив Chrome for Testing 156.0.8078.4, но сервер загрузки вернул данные, не распознаваемые как ZIP. Локальная проверка выполнена через отдельный установленный headless Chromium и штатную настройку executablePath. Базовый рецепт для обычного Codex/CI сохраняет стандартный установщик; его сетевую загрузку в этой среде не считать прошедшей.

Мобильная проверка является эмуляцией браузера, а не испытанием на физическом Samsung. Проверены загрузка страницы, JavaScript-модуль, доступность полного ТЗ и отсутствие горизонтального переполнения. Полноценное приложение, офлайн-PWA, PDF и электрические расчёты ещё не реализованы и не прошли продуктовую приёмку.
