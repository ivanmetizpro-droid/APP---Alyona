# Фактическая готовность

Промежуточное состояние разработки, 16.10.2026.

Добавлены предметная модель, расчётные функции, IndexedDB с защитой ревизий,
JSON-копии, клиентский PDF из публичного DTO, русский адаптивный интерфейс,
SVG-редактор, библиотеки, линии, щит, неизменяемые версии и офлайн-оболочка.
Добавлены исходники Android Java с локальным HTTPS-origin, ограниченным bridge,
SAF save/import, системным share через read-only content provider и release build script.

Это промежуточный коммит: продуктовые проверки и сборка APK ещё выполняются.
Нельзя считать APK выпущенным или приёмку пройденной на основании этого коммита.
SDK устанавливается из официальных архивов Google с проверкой контрольных сумм.
Ключ подписи и пароль хранятся отдельно от checkout, в Git не включаются.
Нормативный автоматический подбор пока не подтверждён; непроверенные условия показаны явно.
