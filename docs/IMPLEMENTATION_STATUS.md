# Фактическая готовность

Промежуточное состояние разработки, 16.10.2026.

Добавлены предметная модель, расчётные функции, IndexedDB с защитой ревизий,
JSON-копии, клиентский PDF из публичного DTO, русский адаптивный интерфейс,
SVG-редактор, библиотеки, линии, щит, неизменяемые версии и офлайн-оболочка.
Добавлены исходники Android Java с локальным HTTPS-origin, ограниченным bridge,
SAF save/import, системным share через read-only content provider и release build script.

Это промежуточный коммит: продуктовые проверки и сборка APK ещё выполняются.
Нельзя считать APK выпущенным или приёмку пройденной на основании этого коммита.
SDK устанавливается из официальных архивов Google с проверкой контрольных сумм.
Ключ подписи и пароль хранятся отдельно от checkout, в Git не включаются.
Нормативный автоматический подбор пока не подтверждён; непроверенные условия показаны явно.

## Точка продолжения после регрессионной проверки

Исправлены стабильные коды работ/SKU при копировании, десятичный HALF_UP цен,
валидация коммерческих данных копий, очередь записи ревизий и ожидание SAF callback.
Добавлены блокировка перекрывающихся штроб (включая обратное направление),
контроль концов перемещённых кабелей и неизвестной мощности светильников.
`npm run check` прошёл; 22 браузерных сценария (11 × desktop/mobile) прошли.
Есть подписанный APK в artifacts, но после последних правок требуется пересборка.
Android 14 AOSP x86_64 emulator загрузился без KVM; установка и native-checks продолжаются.
Первичные PDF ГОСТ с files.stroyinf.ru / meganorm.ru пока блокируются прокси 403;
карточка protect.gost.ru доступна, показывает «Действует», поправки 2018 и 2025,
но API официального просмотрщика возвращает пустой список страниц.
Домены PDF добавлены в черновик сетевых настроек. Ограниченный профиль ещё не завершён.
Приватная подпись: /workspace/private-signing (вне Git). Не менять ключ.

## Сохранённый release-кандидат

18.10.2026: все 30 браузерных проверок прошли; npm run check прошёл.
Ограниченный тепловой профиль реализован и проверен по первичному скану;
