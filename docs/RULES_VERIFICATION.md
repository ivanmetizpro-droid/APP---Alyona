## Ограничения применения

Применяется только при явно подтверждённых условиях: медь, круглая жила,
PVC70, одна цепь без группировки и теплоизоляции, воздух ровно 30 °C,
метод B2 либо C на всей трассе, допустимость 70 °C для клемм, бытовое внутреннее
помещение, подтверждённое наличие PE, отсутствие существенных гармоник.
Для 1ф — два нагруженных проводника; для 3ф — три и подтверждённая симметрия.
Все мощности и cos φ должны быть известны. Неизвестное значение не получает
значение по умолчанию и не даёт кандидатов.

Перечень номиналов, модель/источник аппарата и отношение I₂/In вводятся по
паспорту пользователем, без автоматического допущения 1,45. Отбираются только
кандидаты, удовлетворяющие `Ib ≤ In ≤ Iz` и `I₂ ≤ 1,45 Iz`.
Это ограниченная инженерная координация из ТЗ §16.2; полный нормативный
автоподбор защиты ГОСТ Р 50571.4.43 здесь не заявлен.

Предложение применяется отдельно по нажатию. Сохраняются документ, хеш,
таблица/графа/строка, условия, паспортное отношение, выбранные In/Iz/I₂ и дата.
Фактическая марка кабеля и цены требуют заполнения. Снимок старой сметы не изменяется.
После изменения геометрии/нагрузки интерфейс просит повторно проверить условия.

Не проверены: ток КЗ, отключающая способность, время отключения, селективность,
падение напряжения, гармоники/нейтраль, дифзащита, исполнение PE, минимальное
сечение по назначению, механическая прочность и условия вне профиля.
Итоговый статус электрической проверки остаётся «не завершена».

## Прочие категории

- dataIntegrity: геометрия, зависимости, дубли штроб, концы кабелей, денежные поля,
  целостность импорта, ревизии хранилища — реализованы, покрыты регрессиями.
- userRequirement: потолочное освещение, крепёж 500 мм, отдельные запасы 15%,
  заделка только по флагу — правила пользователя из ТЗ, не универсальная норма.
- engineeringRecommendation: балансировка фаз — детерминированная эвристика;
  резерв щита 20% — редактируемая рекомендация продукта.
