# Дополнение: готовое приложение Android

Дата: 16.10.2026. Это новая обязательная цель пользователя, заменяющая прежний пункт ТЗ «APK/Android вне scope».

Пользователь: «Среда в Codex запущена, командуй дальше сам. Мне нужно готовое для пользования приложение на андроид».

## Результат

Рабочий подписанный установочный APK «Электросмета», который ставится как обычное приложение на Android 14 и работает без сервера/интернета. Одни исходники, PWA-ссылка, макет, APK с пустой стартовой страницей и обещание собрать позже не являются результатом.

Основной функциональный источник — docs/TZ_Elektrosmeta_HTML_CSS_JavaScript_Codex.md. Подготовленная среда содержит только инфраструктуру; продуктовые функции предстоит реализовать.

## Реализация

Сохранить HTML/CSS/JavaScript для рабочей логики и интерфейса. Добавить Android-оболочку на Java/Kotlin или Capacitor, включающую все ресурсы локально. Это обычный APK с иконкой и собственным хранилищем. Никакой зависимости от внешнего опубликованного сайта.

Идентификатор по умолчанию: ru.elektrosmeta.app. Версия 1.0.0, minSdk 26; target/compile SDK выбрать по доступной проверенной цепочке сборки. Поддержка Android 14 обязательна. При изменении target SDK проверить системные отступы, клавиатуру и кнопку «Назад».

Для WebView загружать ресурсы через локальный HTTPS origin (например WebViewAssetLoader). Явно запретить file/universal access и mixed content; не включать произвольную навигацию в WebView, содержащем JavaScript bridge. Внешние URL только отдельным системным браузером по пользовательскому нажатию.

## Нативные функции

- PDF и JSON-бэкап сохраняются через системный выбор файла Android (Storage Access Framework), а не только через blob-download браузера.
- Отправка PDF через системное меню «Поделиться», URI с временным разрешением чтения, без широких разрешений на файлы.
- Импорт JSON через системный выбор файла с валидацией перед изменением данных.
- Данные проектов переживают закрытие приложения и повторный запуск. Честно обработать потерю данных при удалении приложения; реализовать экспорт и восстановление.
- Кнопка «Назад» сначала закрывает диалог/внутренний экран, а не уничтожает незаписанный проект.
- Офлайн-ресурсы, кириллические шрифты и PDF-библиотеки находятся внутри APK.

## Функции первой готовой версии

Два режима сметы, карточка объекта, прайс, материалы и приборы, реальные размеры плана, точки/высоты, линии, физические трассы и штробы, щит, нагрузки/фазы, расчёт всех количеств, ручные корректировки, сохранённые версии, клиентский PDF без расценок строк и срока выполнения, резервная копия. Не ограничиваться только быстрым калькулятором.

Сохранить особые правила: потолочное освещение от выключателя; крепёж только открытой прокладки с шагом 500 мм и запасом 15%; метизы +15% от базы до запаса крепежа; грунтовка/смесь только при заделке; коэффициент сложности только на работы; старые сметы не меняются от нового прайса.

Не выдумывать нормы электрики. Автоматические рекомендации доступны только для документированного ограниченного профиля, непроверенное явно обозначено. Ручная работа и коммерческая смета сохраняются при неполной электрической проверке, без заявления о нормативном удостоверении проекта.

## Сборка и подпись

Установить нужные инструменты самостоятельно из официальных источников. Использовать воспроизводимый build script/Gradle wrapper и CI, фиксировать версии. Изготовить release APK с android:debuggable=false и проверить подпись apksigner verify. Если требуется первый персональный ключ подписи — создать его, хранить вне публичного Git и отдельно сохранить для обновлений; пароли не печатать в логах и не коммитить.

При недоступности сети в одной среде проверить разрешённый официальный путь сборки в GitHub Actions или доступную среду Codex. Не выдавать неподписанный архив/HTML за APK. Реальный технический блокер подтвердить логом и закончить независимые части.

## Проверка

Выполнить значимые unit/e2e тесты и критерии ТЗ, проверить PDF извлечением текста и визуально. По возможности выполнить установку и запуск APK на Android-эмуляторе; записать реальную среду. Нельзя объявлять тестирование на телефоне, если было только Chromium mobile emulation. Отдельно проверить native bridge: save/share/import и отмену системных диалогов.
