# Требования, реализация и проверки

Источники требований: [полное ТЗ](TZ_Elektrosmeta_HTML_CSS_JavaScript_Codex.md)
и [Android-дополнение](ANDROID_DELIVERY.md), заменяющее прежнее исключение APK
из объёма. Эта карта показывает места реализации и сценарии проверки;
фактические результаты запусков записываются в [ACCEPTANCE.md](ACCEPTANCE.md).
Наличие теста само по себе не означает пройденную приёмку на Android.

| Требование / критерии | Реализация | Проверки |
|---|---|---|
| Ручная смета, цены, сложность, точные деньги — C18–C23, A01 | `js/app.js`, `js/calc/engine.js`, `js/domain/units.js` | `calculations.test.mjs`: C18–C23, десятичный HALF_UP; `application.spec.js`: ручная смета, строка и итог 0,29 × 550 коп. = 1,60 ₽ |
| Геометрия и высоты — C01–C05, A02 | `js/domain/geometry.js`, `js/editor/svg-editor.js`, `js/calc/engine.js` | C01–C05; точное редактирование и повторное открытие плана; сохранение геометрии при жестах |
| Физические кабели, гофра, штробы, крепёж и расход — C03–C12, C24 | `js/calc/engine.js`, `js/domain/model.js` | C03–C12, C24; общая трасса, раздельные запасы, фасовки, заделка по флагу |
| Геометрические конфликты и доступное удаление — A15 | `js/domain/geometry.js`, `js/app.js`, `js/editor/svg-editor.js` | Перекрытия и обратные штробы; несовпадающие концы кабеля; удаление стены после перезапуска и отмена |
| Выбор участков и линий по именам, порядок кабеля, плоскость штробы | `js/app.js`, `js/ui.js` | E2E именованных списков участков физического кабеля и линий аппарата |
| Приборы, снимки библиотек, неизвестная мощность — C10, A04, A23 | `js/domain/model.js`, `js/calc/engine.js`, `js/app.js` | C10; CRUD библиотек; неизвестная мощность светильника не считается подтверждённым нулём |
| Токи, фазы, щит — C13–C17, A19–A20 | `js/calc/engine.js`, `js/app.js` | C13–C17; ручные закрепления; общий УЗО и отдельный дифавтомат без повторного учёта |
| Ограниченный рабочий профиль — ТЗ 17.1, A13–A14 | `js/rules/profile.js`, [RULES_VERIFICATION.md](RULES_VERIFICATION.md) | `profile.test.mjs`: строки первичного источника, применимость, отказы, перегрузка, паспортный I₂/In; E2E явного применения |
| Версии и копирование — A05–A06, A16, A24 | `js/calc/engine.js`, `js/domain/model.js` | Неизменяемый snapshot; копия сохраняет SKU/коды и сумму, переназначает объектные связи; стабильность версии после изменения плана/цен |
| Локальное сохранение — A02, A17–A18 | `js/storage/db.js`, `js/app.js` | E2E повторного открытия, конфликта ревизий, ошибки квоты и быстрого последовательного ввода |
| JSON, валидация до замены — A10–A11 | `js/io/backup.js`, `js/io/validation.js` | Полный round-trip; новый профиль; отказ при неверных количествах, ценах, типах, обязательных полях и ссылках без изменения текущих данных |
| Клиентский PDF — A07–A09, A24 | `js/pdf/generate.js`, публичный DTO в `js/calc/engine.js` | E2E кириллицы и 300 строк; проверка публичного состава; отсутствие внутренних цен; стабильность старой версии |
| Офлайн и адаптивность — A12, A22 | Локальные ресурсы, `sw.js`, `css/`, `js/editor/svg-editor.js` | E2E офлайн-перезапуска, редактора и PDF, размеров desktop/mobile и жестов |
| Android local HTTPS, SAF, share, «Назад» — A03, A25 | `android/app/src/main/java/ru/elektrosmeta/app/`, `android/app/src/main/AndroidManifest.xml` | `android/tests/NativeChecks.java`; E2E ожидания SAF callback и отмены; реальные результаты Android — в ACCEPTANCE.md |
| Подписанный release и сохранение ключа | `scripts/build-android.sh`, `scripts/create-signing-key.sh` | `apksigner verify`, сведения APK и SHA-256; ключ и его резервная копия хранятся вне Git |

Файлы тестов: [расчёты](../tests/unit/calculations.test.mjs),
[профиль](../tests/unit/profile.test.mjs),
[пользовательские сценарии](../tests/e2e/application.spec.js),
[Android-проверки](../android/tests/NativeChecks.java).

Ограниченный профиль проверяет тепловых кандидатов для документированных
условий. Он не заменяет проверку КЗ, отключения, селективности, PE,
падения напряжения и остальных условий безопасности. Статус полной
электротехнической проверки остаётся «не завершена».
