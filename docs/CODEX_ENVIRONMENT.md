# Настройка среды Codex

Целевой репозиторий: `ivanmetizpro-droid/APP---Alyona`, ветка `main`.
Назначение: разработка «Электросметы» на HTML/CSS/JavaScript.

## Настройки для веб-интерфейса

| Поле | Значение |
|---|---|
| Название | Электросмета — APP---Alyona |
| Репозиторий | ivanmetizpro-droid/APP---Alyona |
| Ветка | main |
| Образ | Standard/universal, если доступен |
| Node | 24, рекомендуемая локально проверенная версия в .nvmrc |
| Setup script | bash .codex/setup.sh |
| Maintenance script | bash .codex/maintenance.sh |
| Секреты / API-ключи | Не требуются для текущего локального приложения |
| Доступ агента в интернет | Существующее стандартное ограничение; не менять на unrestricted |

Setup использует сеть для npm и Chromium. Во время разработки официальные нормы проверяются через разрешённые инструменты поиска/чтения; отсутствие сетевого источника нельзя компенсировать вымышленной таблицей.

Эти настройки являются подготовленным рецептом. Они не считаются применёнными к аккаунту, пока их сохранение не подтверждено веб-интерфейсом Codex. При подготовке браузер открыл публичную страницу Codex с кнопкой входа; авторизованная среда ещё не подтверждена.

## Проверка после создания

1. В репозитории должны присутствовать main, AGENTS.md, package-lock.json и файлы ТЗ.
2. Запустить проверку setup-скрипта из интерфейса среды.
3. Убедиться, что npm ci, подготовка vendor, Chromium и тесты завершились без ошибок.
4. В новой задаче выбрать эту среду/репозиторий и передать текст из docs/PROMPT_CODEX_Elektrosmeta.txt.

## Официальные основания

- Настройка setup и maintenance, кеш контейнеров: https://learn.chatgpt.com/docs/environments/cloud-environment
- Инструкции AGENTS.md: https://learn.chatgpt.com/docs/agent-configuration/agents-md

AGENTS.md — краткое руководство для агента; полный объём продукта расположен в отдельном ТЗ, чтобы не перегружать автоматически читаемые инструкции.
