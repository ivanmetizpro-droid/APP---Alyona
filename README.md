# Электросмета

Рабочее приложение электрика для Android. Разработка по ТЗ: план, линии, материалы, щит, смета и клиентский PDF.

Подготовленные исходники и инфраструктура будут добавлены в этот репозиторий. Цель текущего этапа — подписанный установочный APK для использования на Android без сервера.
